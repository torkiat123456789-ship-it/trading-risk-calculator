# Trading Risk Calculator

เว็บแอปคำนวณขนาดการเปิดสถานะ (Lot Size) จากเงินทุน เปอร์เซ็นต์ความเสี่ยงต่อไม้ และจุด Stop Loss พร้อมคำนวณ Risk:Reward แจ้งเตือนระดับความเสี่ยง และตารางจำลองการแพ้ติดกัน

## ฟีเจอร์
- คำนวณ Lot Size อัตโนมัติ (ปัดลงเพื่อไม่ให้เสี่ยงเกินที่ตั้งไว้)
- คำนวณกำไรเมื่อถึง Take Profit และอัตราส่วน Risk:Reward
- แบ่งระดับความเสี่ยง: ปลอดภัย / ปกติ / เสี่ยงสูง / อันตราย
- ตารางจำลองเงินคงเหลือเมื่อแพ้ติดกัน 3, 5, 10, 20 ไม้
- ตรวจสอบข้อมูลที่กรอกผิดพร้อมข้อความแจ้งเตือน
- รองรับ Forex, ทองคำ และกำหนดมูลค่าต่อ pip เอง
- รองรับมือถือ และโหมดมืด/สว่างตามเครื่อง

## สูตรหลัก
```
เงินที่ยอมเสีย = เงินทุน × (% ความเสี่ยง ÷ 100)
Lot = เงินที่ยอมเสีย ÷ (Stop Loss (pips) × มูลค่าต่อ pip ต่อ 1 Lot)
```
ตัวอย่าง: ทุน $1,000 เสี่ยง 1% SL 50 pips (EUR/USD, $10/pip) → 10 ÷ (50 × 10) = **0.02 Lot**
